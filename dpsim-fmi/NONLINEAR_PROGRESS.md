# Current nonlinear FMI validation status

The final implementation, validation scope and explicit unsupported cases are documented in [NONLINEAR.md](NONLINEAR.md). Executed comparisons are kept in the five case directories under [examples](examples/README.md). Generated metrics, runs and detailed development evidence remain under the repository build directory on the SSD.

The switched converter is validated against independent matched 1 µs MATLAB physical references for native balanced/unbalanced switched loads and grid sag/phase/frequency disturbances, within the recorded error margins. Its practical 50 µs single-pass multirate path is also validated through 0.2 s runs and crosses its 1 µs internal events with 50 internal steps per network step. Loaded-start, doubled-impedance weak-grid, and unbalanced-sag smoke cases complete at 50 µs. The generic two-converter example completes with two independently instantiable three-phase FMUs on one native EMT network. The available MathWorks export explicitly permits only one instance per process; no second independent converter export is available, so two switched-converter validation remains externally blocked. These limits must not be described as universal FMU support.
