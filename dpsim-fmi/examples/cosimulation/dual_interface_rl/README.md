# Dual-interface three-phase R-L test model

This deterministic FMI 3 model exposes **both** `ModelExchange` and
`CoSimulation` from the same FMU. The checked-in source is a small FMI 3 C++
implementation, rather than an archive relabeled from another interface. Its
continuous branch equations are `L * di/dt = u - R*i`, with `R = 8 ohm` and
`L = 20 mH`. The CS implementation advances this equation exactly over each
communication interval while holding the voltage input constant.

The DPsim grid uses a 2 ohm, 10 mH source impedance, a 100 ohm shunt load, and
the FMU branch at the PCC. The three-phase source ramps from zero over 10 ms,
then applies a balanced 0.75 pu sag from 40 ms through 60 ms. The same FMU,
initial values, network, timestep and event schedule are used for ME and CS.
The DPsim CS coupling is explicit: it stamps the last accepted FMI current and
advances the FMU once using the previous PCC voltage. It does not claim
Newton-converged Co-Simulation.

## Rebuild and run

From the repository root:

```sh
bash dpsim-fmi/examples/cosimulation/dual_interface_rl/build_fmu.sh
cmake -S . -B build-fmi-cosim
cmake --build build-fmi-cosim --target FMI_EMT_Ph3_DualInterfaceRL -j4
```

Run the two modes and the fine-step DPsim ME reference in separate directories:

```sh
RUNNER="$PWD/build-fmi-cosim/dpsim-fmi/FMI_EMT_Ph3_DualInterfaceRL"
FMU="$PWD/build-fmi-cosim/dual-interface-rl-fmu/ThreePhaseRL.fmu"
mkdir -p build-fmi-cosim/dual-interface-rl/{me,cs,me_fine}
(cd build-fmi-cosim/dual-interface-rl/me && "$RUNNER" me "$FMU" 0.08 10e-6 1)
(cd build-fmi-cosim/dual-interface-rl/cs && "$RUNNER" cs "$FMU" 0.08 10e-6 1)
(cd build-fmi-cosim/dual-interface-rl/me_fine && "$RUNNER" me "$FMU" 0.08 2.5e-6 1)
```

The resulting CSV logs are `logs/dual_interface_rl_me.csv` or
`logs/dual_interface_rl_cs.csv` in each run folder.

The independent native Simulink state-space reference is generated by
`matlab/run_native_reference.m`. It creates a 2.5 us fixed-step RK4 model and
writes its CSV and timing manifest under the build directory. The executed
comparison notebook is `../FMU_Mode_Comparison.ipynb`; it contains inverter
ME-versus-Simulink results as a separate case, dual-interface waveforms,
error metrics, timings, and limitations.

The MathWorks inverter FMU in `examples/inverter/sources` is FMI 3 Model
Exchange only. It cannot be used for the CS run; this R-L model provides the
same-archive ME/CS test while keeping the inverter results clearly separate.
